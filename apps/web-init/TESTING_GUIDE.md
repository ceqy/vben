## 🧪 测试步骤

### 步骤 1: 访问应用

1. 确保开发服务器正在运行:
   ```bash
   pnpm --filter @vben/web-init dev
   ```

2. 打开浏览器访问: http://localhost:5555

3. 使用默认账号登录:
   - 用户名: `vben`
   - 密码: `123456`

### 步骤 2: 测试工作台

登录后应该看到 **ERP 工作台**，包含：

- ✅ 收藏的功能（顶部左侧）
- ✅ 最近访问（顶部右侧）
- ✅ 7 个功能模块卡片：
  - IAM (身份与访问) - 蓝色
  - MDM (主数据) - 紫色
  - FI (财务管理) - 绿色
  - SCM (供应链) - 橙色
  - MFG (生产制造) - 红色
  - SD (销售分销) - 青色
  - SYS (系统管理) - 灰色

每个卡片应显示：
- 模块图标和名称
- 模块描述
- 统计数据（2 个指标）
- 快捷入口菜单（2-3 个）

### 步骤 3: 测试菜单搜索 (⌘K)

1. **打开搜索**:
   - Mac: 按 `⌘ + K`
   - Windows: 按 `Ctrl + K`
   - 或点击顶部工具栏的"搜索菜单..."按钮

2. **搜索测试**:
   ```
   输入 "用户" → 应显示 "用户管理"
   输入 "IAM" → 应显示所有 IAM 模块菜单
   输入 "库存" → 应显示 "库存概览"
   输入 "订单" → 应显示 "生产订单" 和 "销售订单"
   ```

3. **键盘操作**:
   - `↑` `↓` 键选择菜单
   - `Enter` 确认跳转
   - `ESC` 关闭搜索

4. **验证功能**:
   - ✅ 关键词高亮显示
   - ✅ 显示面包屑导航
   - ✅ 显示模块代码标签
   - ✅ 实时搜索（300ms 防抖）

### 步骤 4: 测试收藏功能

1. 在工作台模块卡片中，鼠标悬停在快捷菜单上
2. 点击右侧的星标图标
3. 菜单应该添加到顶部"收藏的功能"区域
4. 再次点击星标可以取消收藏

### 步骤 5: 测试菜单导航

1. 点击任意快捷菜单（如"用户管理"）
2. 应该跳转到对应页面
3. 页面应显示：
   - 页面标题
   - 4 个统计卡片
   - 示例内容区域

4. 检查左侧菜单栏是否显示 ERP 模块菜单

### 步骤 6: 测试最近访问

1. 访问几个不同的菜单页面
2. 返回工作台首页
3. "最近访问"区域应显示刚才访问的菜单
4. 点击可以快速跳转

## 🐛 常见问题

### 问题 1: 搜索框不显示

**解决方案**:
1. 检查 `menu-search.vue` 是否正确导���到 `basic.vue`
2. 查看浏览器控制台是否有组件错误
3. 确认 `toolbar-left` 插槽是否被正确使用

### 问题 2: Mock API 404

**解决方案**:
1. 确认 Nitro Mock Server 是否启动（应显示在终端）
2. 检查 API 路径是否正确（应为 `/api/menu/...`）
3. 查看 `apps/backend-mock/api/` 目录下文件是否存在

### 问题 3: 工作台模块不显示

**解决方案**:
1. 打开浏览器控制台查看错误信息
2. 检查 API 返回数据格式
3. 确认 `workspace/index.vue` 组件是否正确加载

### 问题 4: 图标不显示

**解决方案**:
1. 确认使用的是 `lucide:` 前缀的图标
2. 检查 UnoCSS 配置是否正确
3. 查看图标名称是否拼写正确
